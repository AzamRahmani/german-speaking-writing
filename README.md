# German Speaking and Writing

This project documents my German speaking and writing practice using
the book **Starten wir! B1**.

## Goals

- Improve my German speaking skills
- Improve my German writing skills
- Practise grammar and vocabulary
- Track my corrections and progress
- Prepare for my German course

## Project Structure

Each lesson contains separate folders for speaking and writing:

- `speaking`: speaking tasks, corrections and useful expressions
- `writing`: writing tasks, corrections and grammar explanations

## Learning Process

For every activity, I:

1. complete the first attempt,
2. review my mistakes,
3. add the corrected version,
4. study new vocabulary and grammar,
5. record my score,
6. set a goal for the next activity.
